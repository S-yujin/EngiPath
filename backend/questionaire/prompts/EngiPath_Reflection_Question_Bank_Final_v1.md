## Runtime Principle

The 50 questions form a **question bank**, not a fixed questionnaire.

A typical student session should select approximately:

- **8–10 Core questions**
- **4–5 Contextual questions**
- **2–4 Adaptive questions**

for roughly **15–19 student-facing questions**.

The interaction should follow a branching reflection flow:

**Question → Response → Interpret signal → Ask follow-up if useful → Move on when enough information is available**

Adaptive follow-up depth should normally be limited to one or two additional questions per topic.

The system should avoid presenting highly similar questions in the same session unless a follow-up is genuinely needed. In particular:

- Q41 and Q42 should not normally appear together.
- Q45 and Q46 should not normally appear together.
